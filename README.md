# MCC launcher
A small command-line fast Minecraft launcher
# Instructions
Get the [latest release here.](https://github.com/billhantoncoder/mcc-launcher/releases)
Unzip the folder, then run the install.bat file. After that, you can delete the folder.
To uninstall, use the options in the program.
# Usage
Simply open up your command prompts, type: `mcc`
